# Task Manager

Angular 19 SPA: список задач, фильтр по статусу, создание и смена статуса. Mock API — json-server 0.17.4.

## Как запустить

Node.js 22 LTS.

```bash
git clone https://github.com/An11y/task-manager.git
cd task-manager
npm install
```

Терминал 1:

```bash
npm run api
```

Терминал 2:

```bash
npm start
```

Приложение: http://localhost:4200/tasks  

Запросы идут на `/api/tasks`, dev-server проксирует их на `http://127.0.0.1:3000` (см. `proxy.conf.json`).

```bash
npm run build
npm test
```

## Решения и компромиссы

1. Фильтр и поиск в query string. Загрузка через HttpClient и `switchMap` — при быстрой смене параметров остаётся ответ последнего запроса.
2. Состояние списка и флагов запросов — на странице задач. Фильтр/поиск берутся из URL.
3. Новая задача всегда со статусом `new`. Если текущий фильтр или поиск её не пропускают, список не меняется, показывается сообщение об успешном создании.
4. Статус только вперёд: `new → in_progress → done`. В UI сразу optimistic update, при ошибке откат.
5. Поиск с debounce ~350 мс, на API — `title_like`.
6. Без удаления, редактирования и пагинации.
